🔀 include 디렉티브 태그 vs include 액션태그

같은 "포함"인데 무엇이 다른가 — 9단계로 나란히 비교

1단계파일 준비
2단계변환 (java 만들기)
3단계컴파일 · 실행
4단계결과 비교

① include 디렉티브 태그

<%@ include file="./inc/OuterPage1.jsp" %>
버튼을 눌러 시작하세요.

② include 액션 태그

<jsp:include page="./inc/OuterPage2.jsp"/>
버튼을 눌러 시작하세요.
