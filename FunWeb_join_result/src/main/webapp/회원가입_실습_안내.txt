====================================================================================================
  회원가입 기능 만들기 실습 안내   (FunWeb MVC 프로젝트)
====================================================================================================
  이미 완성된 로그인/로그아웃과 똑같은 구조로 회원가입을 직접 만들어 본다.
  각 파일의 주석 바로 아래 빈 줄에 코드를 작성하면 된다.
====================================================================================================
  [작업 순서]  아래 순서대로 해야 오류가 적다
----------------------------------------------------------------------------------------------------
   순서   파일                    할 일                              실습 번호
   ----   ---------------------   --------------------------------   ---------
    1     MemberVO.java           name, email 변수와 메소드 추가      실습 1            #@#####
    2     MemberDAO.java          중복검사 + INSERT 메소드 작성       실습 2-1, 2-2       #@#####
    3     MemberService.java      중복검사 전달 + 가입 업무 작성      실습 3-1, 3-2          #@#####
    4     MemberController.java   join.do 분기 + join() 작성          실습 4-1, 4-2    #@#####
    5     join.jsp                폼 연결 + 버튼 + 실패 메시지        실습 5-1~3
   ** 안쪽(데이터)부터 바깥쪽(화면)으로 만드는 순서다. **
====================================================================================================
  [완성 후 흐름]  로그인과 똑같은 6단계 왕복이다
----------------------------------------------------------------------------------------------------
 join.jsp --> Controller --> Service --> DAO --> MySQL
   (View)     join.do 분기   중복검사    isDuplicated   select count
                             후 저장     insertMember   insert into
                                |                            |
                                +<----- true/false <---------+
                                |
                    성공: 세션 저장 + index.jsp 로 redirect
                    실패: joinMsg 담아 join.jsp 로 forward
====================================================================================================
  [테스트 방법]
----------------------------------------------------------------------------------------------------
   1. 톰캣 실행 후 join.jsp 접속
   2. 새 아이디(예: park / 1111 / 박문수 / park@test.com) 입력 후 Submit
      -> 메인 화면으로 이동 + 헤더에 "park님 환영합니다" 표시되면 성공
   3. MySQL 에서 확인 :  select * from t_member;
      -> park 행이 추가되어 있어야 한다
   4. 같은 아이디(park)로 또 가입 시도
      -> "이미 사용 중인 아이디입니다." 경고창이 뜨면 중복검사 성공
   5. logout 후 park / 1111 로 로그인
      -> 로그인되면 저장이 제대로 된 것이다
====================================================================================================
  [자주 나는 오류와 원인]
----------------------------------------------------------------------------------------------------
   증상                              원인
   -------------------------------   ------------------------------------------
   404 오류                          form 의 action 을 join.do 로 안 고침
   버튼을 눌러도 반응 없음            input type 이 button 그대로 (submit 아님)
   입력값이 전부 null                 input 의 name 과 getParameter 이름이 다름
   한글 이름이 깨짐                   doHandle 의 setCharacterEncoding 순서 확인
   500 오류 (NullPointerException)    VO 에 name/email 변수나 생성자를 안 만듦
   가입은 되는데 목록에 없음          executeQuery 를 씀 (INSERT 는 executeUpdate)
