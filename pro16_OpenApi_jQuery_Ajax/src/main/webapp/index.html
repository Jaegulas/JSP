키 없이 바로 쓰는 무료 Open API 실습

이 프로젝트의 특징
회원가입, API 키 발급, 활성화 대기, 신용카드 등록이 전부 필요 없습니다. 톰캣을 실행하고 화면을 열면 그 자리에서 바로 실제 데이터가 나옵니다.

예제 목록

번호내용사용 API핵심 문법
1 실시간 코인 시세판 자동 갱신 업비트 시세 조회 API $.ajax + setInterval
2 환율 계산기 ExchangeRate 환율 API $.getJSON + $.each
3 서버를 거쳐 호출하기 실무 표준 위 두 API 공용 JSP 프록시 + $.ajax

사용하는 요청 주소

[1] 업비트 - 마켓(종목) 목록
https://api.upbit.com/v1/market/all

[2] 업비트 - 현재 시세
https://api.upbit.com/v1/ticker?markets=KRW-BTC,KRW-ETH

[3] 환율 (미국 달러 기준)
https://open.er-api.com/v6/latest/USD

세 주소 모두 브라우저 주소창에 그대로 붙여넣으면 결과를 바로 볼 수 있습니다.
API 키를 붙이지 않아도 됩니다.

왜 이 API 들을 골랐는가

기준이유
키 발급 불필요수업 시간에 발급 대기로 40분을 버리는 일이 없습니다.
CORS 허용브라우저에서 직접 호출해도 차단되지 않습니다. 응답 헤더에 access-control-allow-origin 이 있습니다.
응답 구조가 다름1번은 대괄호 배열, 2번은 중괄호 객체입니다. 두 가지 형태를 모두 연습합니다.
값이 계속 변함새로고침할 때마다 숫자가 바뀌므로 실시간 통신이라는 것을 눈으로 알 수 있습니다.

응답 데이터의 모습

[업비트 시세]  대괄호로 시작하는 배열입니다. 종목 1개만 물어봐도 배열로 옵니다.

[
  {
    "market"             : "KRW-BTC",       <- 종목 코드
    "trade_price"        : 110860000,       <- 현재가
    "change"             : "FALL",          <- RISE(상승) EVEN(보합) FALL(하락)
    "change_price"       : 66000,           <- 전일 대비 변동 금액 (항상 양수)
    "signed_change_rate" : -0.0005949913,   <- 변동률. 음수 부호가 붙어 있음
    "acc_trade_price_24h": 123456789000     <- 24시간 누적 거래대금
  }
]

주의. 배열이므로 첫 칸을 꺼내려면 data[0].trade_price 라고 써야 합니다.


[환율]  중괄호로 시작하는 객체입니다.

{
  "result"               : "success",
  "base_code"            : "USD",
  "time_last_update_utc" : "Thu, 03 Sep 2026 00:02:31 +0000",
  "rates" : {                                <- 값이 또 객체입니다
      "KRW" : 1361.139243,
      "JPY" : 159.088772,
      "EUR" : 0.863349
  }
}

주의. 통화가 160개가 넘게 들어 있습니다. rates.KRW 처럼 점을 두 번 찍어 꺼냅니다.

실행 방법

1. 이클립스에서 File - Import - WAR file 로 이 프로젝트를 가져옵니다.
2. 톰캣을 실행합니다.
3. 아래 주소로 접속합니다.

   http://localhost:8090/pro18_OpenApi_jQuery/

4. 1번부터 순서대로 실행합니다.
