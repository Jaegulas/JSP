키 없이 쓰는 무료 API 카탈로그

회원가입, 인증키 발급, 활성화 대기, 신용카드 등록이 전혀 필요 없는 API 24종입니다. 모든 항목은 2026년 9월 4일에 실제로 호출해 상태코드와 CORS 허용 여부를 확인했습니다.

먼저 읽어 주세요

여기 실린 API 를 고른 기준 3가지
1. 인증키가 필요 없습니다. 주소를 브라우저 주소창에 붙여넣으면 바로 결과가 나옵니다.
2. 응답 헤더에 access-control-allow-origin 이 있습니다. 브라우저에서 직접 호출해도 차단되지 않습니다.
3. 응답이 JSON 입니다. fetch 나 $.ajax 로 배운 문법을 그대로 쓸 수 있습니다.
주의할 점 3가지
1. 무료 API 는 예고 없이 주소가 바뀌거나 서비스가 중단될 수 있습니다. 수업이나 발표 전에 반드시 한 번 호출해 보세요.
2. 호출 횟수 제한이 있습니다. 자동 갱신 간격을 5초보다 짧게 잡지 마세요.
3. 상업적으로 쓰려면 각 사이트의 이용 약관을 확인해야 합니다. 학습과 포트폴리오는 대부분 허용됩니다.
분류 전체 국내 날씨·환경 금융·경제 생활·정보 연습용 재미·이미지

API 를 처음 만났을 때의 확인 순서

순서할 일확인 방법
1주소창에 그대로 붙여넣기결과가 보이면 그 API 는 살아 있습니다. 코드를 짜기 전에 먼저 합니다.
2배열인지 객체인지 확인대괄호로 시작하면 배열, 중괄호로 시작하면 객체입니다.
3필요한 값의 경로 찾기data.rates.KRW 처럼 점을 몇 번 찍어야 하는지 미리 적어 둡니다.
4CORS 허용 여부 확인F12 Network 탭에서 응답 헤더에 access-control-allow-origin 이 있는지 봅니다.
5차단되면 프록시 사용서버(jsp)에서 대신 호출하게 만듭니다. 키가 필요한 API 도 마찬가지입니다.
키가 필요한 API 는 언제 쓰나요
실시간 버스 도착, 국내 대기질 공식 데이터, 지도, 결제 같은 것은 예외 없이 인증키가 필요합니다. 이런 API 는 반드시 서버(jsp)를 거쳐 호출해 키를 숨겨야 합니다. 또한 발급 후 반영에 시간이 걸리므로 수업 전날 미리 준비해야 합니다.
