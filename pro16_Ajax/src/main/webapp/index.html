jQuery Ajax 기존 JSP 프로젝트 유지보수용

번호내용핵심 문법
1$.ajax 로 text 응답받기dataType : "text"
2$.ajax 로 json 응답받기dataType : "json"
3JSON 배열 반복 출력$.getJSON + $.each
4아이디 중복체크 (실전)$.ajax + 디바운스

fetch + async/await 실무 표준

번호내용핵심 문법
1기본 문법 (text / json)async · await · try~catch
2아이디 중복체크 (실무 표준)공통 함수 + 타임아웃 + 디바운스
3POST로 데이터 보내기JSON.stringify + 중복클릭 방지
4여러 요청 동시에 보내기Promise.all
5JSON 배열 반복 출력map + join + 백틱

두 방식의 코드 비교

[jQuery]                              [fetch + async/await]

$.ajax({                              async function f(){
    url : "calc.jsp",                     try {
    type : "get",                             const res = await fetch("calc.jsp?v1=10");
    data : { v1 : 10 },                       if(!res.ok) throw new Error(res.status);
    dataType : "json",                        const data = await res.json();
    success : function(response){             // 화면 갱신
        // 화면 갱신                      } catch(err) {
    },                                        // 오류 안내
    error : function(xhttp){              } finally {
        // 오류 안내                          // 뒷정리
    },                                    }
    complete : function(){            }
        // 뒷정리
    }
});

차이점 정리
  1. jQuery 는 404, 500 이 오면 자동으로 error 로 넘어간다.
     fetch 는 res.ok 를 직접 검사해야 한다.
  2. jQuery 는 dataType:"json" 이면 자동 변환된다.
     fetch 는 await res.json() 을 직접 호출해야 한다.
  3. jQuery 는 별도의 파일을 불러와야 동작한다.
     fetch 는 브라우저에 기본으로 들어 있다.

모든 예제는 화면 전체를 새로 그리지 않고 특정 부분만 갱신합니다. F12를 눌러 개발자도구의 Network탭을 함께 보면 실제 요청과 응답을 확인할 수 있습니다. Network탭에서 요청 하나를 클릭하면 Headers(요청 정보), Payload(보낸 값), Response(서버가 보낸 답) 를 각각 눈으로 확인할 수 있습니다.
